🛡️ PLEROMA

Zero-Trust OS Fortress for Local AI Agents

The Canon (Core Absolute Defense)
👁️

Raphael (Environment Seal)

Audits the execution environment upon startup. Prevents the AI from operating in contaminated or unapproved external cloud CI/CD pipelines.

os.getenv() validation
📜

Gabriel (AST Inquisition)

Parses the Abstract Syntax Tree (AST) of AI-generated code before execution. Detects and violently rejects the summoning of banned modules.

ast.parse() pre-execution
⚔️

Michael (OS Deep Hook)

The final absolute defense. Uses Python's native audit hooks to physically intercept and block unauthorized system calls deep within the OS at runtime.

sys.addaudithook() runtime

Local Doctrines (Extensibility)
📕

The Rubrics

A declarative configuration file (`rubric.json`) at the project root. Allows developers to define project-specific banned modules and events without altering the core Canon.

JSON Configuration
⛪

The Homilies

A designated directory (`homilies/`) for dropping custom Python plugins (MODs). Pleroma dynamically loads and preaches these custom validation logics at startup.
